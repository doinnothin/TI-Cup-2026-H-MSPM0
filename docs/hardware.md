# 硬件与外设职责划分

## 目标

- MCU：MSPM0G3507，采用由 `empty.syscfg` 所表示的项目板配置。
- 主执行器：X42S 步进电机，使用 `user/code/x42s.*` 中的 X 固件协议。
- 视觉数据由 MCU 经 UART3 消费；视觉识别固件不在本仓库内。
- 底盘使用项目的电机/PWM 与编码器服务；使用前请对照实际板卡核验物理接线。

## 当前 SysConfig 分配

以下数值读取自已签入的 `empty.syscfg` 与生成的 `ti_msp_dl_config.h`，而非依据历史日志推断：

| 外设 | SysConfig 实例 | 引脚 | 固件职责 |
|---|---|---|---|
| UART0 | `PRINT` | PA0 TX / PA1 RX | X42S 执行器协议传输（`user/code/x42s.*`）；SysConfig 的遗留实例名为 PRINT。 |
| UART1 | `DEBUG` | PB6 TX / PB7 RX | 调试/日志通道。 |
| UART2 | `GYRO` | PA21 TX / PA24 RX | 陀螺仪串口接口。 |
| UART3 | `VISION` | PA26 TX / PA25 RX | 视觉数据链路。 |
| TIMG6 | `Timer_Control` | 内部 | 控制时基中断。 |

`user/main.c` 中当前的前台按键路由为：

| 按键 | 动作 |
|---|---|
| PB21 | 停止活动任务并请求既有的停止处理。 |
| PB11 | 启动 Q5。 |
| PB24 | 当 `Q6_TASK_ENABLE=1` 时启动 Q6；否则启动 Q2 底盘路线。 |
| PA28 | 启动 Q4。 |
| PA31 | Q3 清零/参考与启动流程；首次按下会布防本次会话，正式启动需要既有的二次按下/视觉居中条件。 |

这些是源码/SysConfig 观察结果，不能替代对板卡上物理按键标识与接线的检查。

生成文件还配置了底盘 PWM、GPIO 按键、编码器、OLED、时钟与中断路由。不要仅凭文档就改动这些内容。`empty.syscfg` 仍是权威来源；生成的宏是当前生成映射的证据。

## 运行与安全边界

- 保持当前由 TIMG6 驱动的节拍与主循环任务顺序。
- ISR 应只捕获有界的事件/数据或推进计时状态。它们不得阻塞于串口发送，也不得刷新 OLED。
- 保持 X42S 协议族、命令组帧、单位、回复处理、存储零点序列与终端停止行为不变。
- 硬件验证需要匹配的板卡、执行器固件、接线、供电与安全的机械支撑。编译成功并不构成物理正确性的证据。
