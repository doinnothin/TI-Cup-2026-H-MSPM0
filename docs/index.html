⚽ 车载平衡滚球运动控制系统

基于 TI MSPM0G3507 的滚球平衡控制固件：视觉串口反馈 + 球位置闭环 + 摆杆几何映射 + X42S 步进执行器，覆盖第 2～6 问，让钢球在飞驰的小车上稳稳停在指定位置。

💻 GitHub 仓库 📽️ 实机演示 📄 赛题 PDF 📚 详细文档
🎯

双系统解耦

小车运动 + 摆杆滚球两个耦合系统，以共享车辆状态机 + 模式门控复用已验证控制律。

👁️

纯视觉观测

仅有位置测量时用 α-β 估计把速度作为阻尼项，不虚构"速度内环"，贴合真实可观测条件。

🛑

预测性制动

按停车距离模型提前反向阻尼，而不是到点才刹车；兼顾静摩擦起步补偿。

🧪

可复现验证

主机回归（ARM 模拟器）+ ARM 构建 + 参数辨识工具 + 调试案例，全链路留证。
