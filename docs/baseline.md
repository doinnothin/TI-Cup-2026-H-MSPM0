# 源码与构建基线

## 基准判定

本项目包含两个相互关联的工作副本。当前 `s1` 分支基于 Q2–Q5 的项目状态，没有 Q6 任务路径。独立的 Q6 分支新增了 `user/app/q6`、Q6 目标/配置逻辑与 Q6 模式集成。其源码与构建元数据与用户已接受的 Q6 运行记录一致。因此本次清理基于 Q6 集成后的源码快照，而不是仅凭 `s1` 这一目录名。

本仓库覆盖 MCU 控制路径 Q2–Q6。Q1 是外部视觉识别任务，有意排除在范围之外；仅包含 MCU 侧的 UART3 接口。

## 本地 CMake 缓存中观察到的固件变体

| 变体 | 相关编译定义 | 预期用途 |
|---|---|---|
| `build_drive` | `Q6_TASK_ENABLE=1U`，`Q6_STATIC_TEST_MODE=0U`，`Q6_BENCH_AUTO_START=0U`，`Q6_BOOT_AUTO_SELECT=1U`，`Q6_BENCH_EXPLICIT_TARGET_MM=-32768` | 动态/竞赛风格的 Q6 镜像，含捕获目标与 PB24 启动流程。这是缓存证据，并非全新构建的证明。 |
| `build_static` | `Q6_STATIC_TEST_MODE=1U`，`Q6_BENCH_AUTO_START=0U`，`Q6_BOOT_AUTO_SELECT=1U`，`Q6_BENCH_EXPLICIT_TARGET_MM=-32768` | 静态台架变体；切勿将其描述为竞赛镜像。 |
| `build_vehicle_ninja` | `Q6_STATIC_TEST_MODE=0U`，`Q6_BENCH_AUTO_START=1U`，`Q6_BOOT_AUTO_SELECT=1U`，`Q6_BENCH_EXPLICIT_TARGET_MM=-32768` | 自动启动实验变体；烧录前须先核验。 |

Q6 头文件的默认值为：启用该任务，但禁用静态台架模式、自动启动与启动自动选择。CMake 缓存标志会覆盖这些默认值；在任何发布构建之前请检查确切的缓存/编译命令。

PB24 在编译期被复用：当 `Q6_TASK_ENABLE=1` 时它请求 Q6；在禁用 Q6 的替代镜像中，它启动既有的 Q2 路线。因此源码树同时包含两条任务路径，而单一的 PB24 映射无法同时暴露二者。
