# 已知限制

- 本仓库不包含独立的 Q1 视觉算法/固件。它只包含 MCU 侧的 UART3 数据消费端以及控制侧的帧校验。
- Q4/Q5/Q6 共用 `q45_vehicle_control.c`；部分 Q6 适配是按模式门控的分支，而非完全独立的状态机。
- 硬件结果依赖于具体条件。用户的 Q6 验收声明未由本次清理复现；探索性调参不作为已验证结果呈现。
- 当前的 CMake 预设面向 Windows，并使用本地环境变量指定工具路径。干净的检出仍需要正确配置 Arm GNU、CMake/Ninja 以及 TI SysConfig/SDK。
- 代码树中存在第三方 SDK/DriverLib 内容。发布公开版本前，请保留其原始声明并审计确切的可再分发子集；参见 `THIRD_PARTY_NOTICES.md`。
